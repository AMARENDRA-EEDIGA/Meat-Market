# Meat Market

A small project for managing and exploring meat products, pricing, and inventory. This repository contains the backend and frontend code for an application that helps butchers and suppliers track product types, stock levels, and prices.

## Features

- Track different meat products (type, cut, weight, price)
- Inventory levels and alerts
- Simple REST API to manage products
- Basic frontend for browsing and updating inventory

## Getting Started

Prerequisites
- Node.js 16+ and npm
- (Optional) Docker for containerized development

Install

1. Clone the repository:

   git clone https://github.com/AMARENDRA-EEDIGA/meat-market.git
   cd meat-market

2. Install dependencies (backend and frontend if present):

   npm install

Run (development)

- Backend:

  npm run dev --prefix backend

- Frontend:

  npm start --prefix frontend

Testing

- Run tests (if any):

  npm test
